## 十一、Workflow 生成专项测试提示词

以下提示词可直接粘贴到首页输入框测试 Workflow 生成质量：

### W-1: 简单线性流程
```
我要做员工入职流程：HR发offer → 员工签约 → IT开通账号 → 部门分配工位 → 入职培训 → 试用期开始
```

### W-2: 带条件分支
```
客户投诉处理：收到投诉后先分类（产品质量/服务态度/物流问题），不同类型走不同处理流程，最后统一回访确认
```

### W-3: 复杂多步骤
```
我想自动化进出口报关流程，收到委托后先审核报关单据的完整性，然后根据商品描述进行海关编码归类，计算关税，填制报关单，提交海关申报，等待审核放行后通知客户
```

### W-4: 含审批环节
```
采购申请流程：部门提需求 → 采购部询价比价 → 生成采购单 → 部门经理审批（>5万需总监审批）→ 财务审核 → 下单 → 收货验收 → 入库
```

## 十三、端到端完整流程测试

### E2E-1: Workflow 完整生命周期

```
步骤：
1. 首页输入 W-3（进出口报关），等待生成完成
2. 确认有追问的节点（至少确认1个，暂缓1个）
3. 在聊天中输入修改意见，验证画布更新
4. 点击「确认方案」→ 弹窗确认
5. 验证状态变为"技术评审中"
6. 验证聊天显示"正在自动生成技术配置"
7. 打开 /tech，验证列表中出现该方案
8. 点击进入技术方编辑器
9. 验证流程图正确显示
10. 点击「评审通过」
11. 验证状态变为"双方确认"
```

### E2E-2: Agentic 完整生命周期

```
步骤：
1. 首页输入 A-1（小红书运营），等待生成完成
2. 在 AgenticCanvas 中逐阶段确认（回答追问）
3. 内联编辑某个阶段的动作
4. 在聊天中输入修改意见
5. 点击「确认方案」→ 弹窗确认
6. 验证自动生成技术配置
7. 打开 /tech，验证列表中出现该方案
8. 点击进入技术方编辑器
9. 验证 AgenticConfigPanel 显示技能/决策循环等
10. 点击「评审通过」
```

### E2E-3: 打回修改流程

```
步骤：
1. 完成 E2E-1 步骤 1-6
2. 技术方点击「打回修改」
3. 切换到业务方视角
4. 验证状态为"需修改"，TopBar 显示「重新提交评审」
5. 在聊天中修改方案
6. 点击「重新提交评审」
7. 验证状态回到"技术评审中"
```

### E2E-4: Mock 方案评审

```
步骤：
1. 从 /tech 点击「小红书账号运营」(review-1)
2. 验证 AgenticConfigPanel 显示完整技术配置
3. 展开各个折叠区块验证内容
4. 点击「评审通过」
5. 验证状态变为"双方确认"
```
